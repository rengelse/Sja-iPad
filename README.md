# SJA Generator – iPad

Offline-first iPad-versjon av SJA Generator distribuert som PWA via GitHub Pages.

## v0.3.2

Første dedikerte iPad-UI-release:

- landscape med fast, smal rapportnavigasjon
- portrait med `☰ Seksjoner`-drawer
- større touch-flater og 16 px skjemafelt
- dokumentlisten blir kortbasert i portrait
- risiko/hazard-oppsett tilpasset touch og smalere skjerm
- 1–2 kolonner i skjema avhengig av tilgjengelig bredde
- samme SJA-logikk, lagring og PDF-kjerne som tidligere

Se `INSTALLASJON-IPAD.md` for førstegangsoppsett.
