# SJA Generator på iPad

## Én gangs oppsett av GitHub

1. Last inn innholdet i denne pakken til repository `rengelse/Sja-iPad` på branch `main`.
2. Åpne repository på GitHub → **Settings** → **Pages**.
3. Under **Build and deployment / Source**, velg **GitHub Actions**.
4. Åpne fanen **Actions** og vent til `Deploy SJA iPad to GitHub Pages` er grønn.
5. GitHub viser Pages-adressen. For dette repository-navnet vil den normalt være:
   `https://rengelse.github.io/Sja-iPad/`

## På iPad

1. Åpne Pages-adressen i Safari mens iPaden har nett.
2. La SJA Generator åpne ferdig.
3. Trykk Del → **Legg til på Hjem-skjerm**.
4. Start SJA Generator fra ikonet på hjemskjermen.

Etter første komplette innlasting caches programmet lokalt og kan brukes uten internett. SJA-dokumenter, personell og egne maler lagres lokalt på iPaden.
